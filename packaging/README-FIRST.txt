DOTA DRAFT OVERLAY - READ ME FIRST
==================================

1. KEEP THIS WHOLE FOLDER TOGETHER.
   DotaDraftOverlay.exe needs the "_internal" folder that sits right next to
   it. If you move or copy only the .exe somewhere else, Windows shows:
   "Failed to load Python DLL ... python312.dll".

2. Extract the zip completely first (right-click -> Extract All). Do not run
   the program from inside the zip.

3. Want a shortcut on your Desktop? Right-click DotaDraftOverlay.exe ->
   Send to -> Desktop (create shortcut). Do not drag the .exe itself.

4. Your settings and downloaded data are saved in this same folder, so keep it
   somewhere you can write files (Documents or Desktop is fine; Program Files
   is not).

5. Dota 2 must be in "borderless windowed" display mode.

6. Windows may say "Windows protected your PC" because the program is not
   code-signed yet. Click "More info", then "Run anyway".

First run: the Settings window opens by itself. Paste your free Stratz token,
choose your bracket, and click "Update everything".
